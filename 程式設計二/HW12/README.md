# HW12：高鐵訂票系統

> 簡化版的台灣高鐵訂票系統：訂票時隨機產生訂位代號並寫入二進位檔；可用身分證字號與訂位代號查詢或取消訂位。

| 檔案 | 說明 |
|---|---|
| `main.cpp` | 主選單與輸入檢查 |
| `MakingReservation.h`、`makingReservation.cpp` | 訂票 |
| `ReservationHistory.h`、`reservationHistory.cpp` | 查詢與取消 |
| `Reservation.h`、`reservation.cpp` | 訂位資料 |
| `Southbound timetable.dat`、`Northbound timetable.dat` | 南下／北上時刻表 |
| `Reservation details.dat` | 訂位紀錄（範例資料） |
