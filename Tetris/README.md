# Tetris：雙人對戰俄羅斯方塊

> 大學 Java 課程的期末專題：同一台電腦上兩位玩家即時對戰的俄羅斯方塊。玩家消除方塊時會對對手發動技能，比的不只是誰撐得久，還有怎麼干擾對方。

## 功能

- **雙人同機對戰**：左右各一個 10×20 的盤面，各自獨立計時與落下速度
- **基本操作**：移動、旋轉、加速、直接落下、暫存（Hold），並顯示下一個方塊與落點輔助線
- **畫面**：方塊使用漸層與紋理貼圖繪製，視窗啟動時自動最大化
- **結束與重來**：一方盤面堆到頂端即落敗，跳出對話框詢問是否重新開始

## 對戰技能

一次消除的行數不同，會觸發不同的技能：

| 消除行數 | 技能效果 |
|---|---|
| 1 行 | 調整速度：自己太快時先讓自己慢一點，否則讓對手變快 |
| 2 行 | 封鎖暫存：先解除自己被封鎖的 Hold，剩下的次數轉成封鎖對手的 Hold |
| 3 行 | 障礙方塊：處理自己盤面上的灰色障礙；沒有可處理的就讓對手接下來出現 2 個障礙方塊 |
| 4 行 | 大招：一次套用上面三種效果，並讓對手 15 秒內無法發動技能 |
| 盤面全消 | 對手盤面整體上推 4 行，底部塞入交錯的障礙列；如果對手最上面 4 行已有方塊就直接落敗 |

被大招封鎖的期間，1～3 行的技能不會發動，畫面上會顯示剩餘秒數。

## 操作

| 動作 | 玩家 1 | 玩家 2 |
|---|---|---|
| 左移／右移 | `J`／`L` | 數字鍵 `4`／`6` |
| 旋轉 | `I` | 數字鍵 `8` |
| 加速下落 | `K` | 數字鍵 `5` |
| 直接落下 | `Space` | 方向鍵 `↓` |
| 暫存方塊（Hold） | `Q` | `Delete` |

## 技術

Java、Swing（`JPanel`、`Graphics2D` 繪圖、`KeyListener`、計時器執行緒）

## 檔案

| 檔案 | 說明 |
|---|---|
| `TetrisGame.java` | 遊戲全部程式碼：方塊（`Shape`）、盤面、技能、繪圖與鍵盤控制 |
| `texture.png` | 方塊紋理 |
| `red.png` | Hold 被封鎖時顯示的圖示 |

## 執行方式

需要 JDK 8 以上。圖片以 `getResource` 從 class 所在目錄讀取，請在本資料夾內編譯執行：

```bash
javac TetrisGame.java
java TetrisGame
```
