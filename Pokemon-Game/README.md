# Pokemon-Game：終端機寶可夢遊戲

> 大一以 C++ 獨立完成的文字介面寶可夢遊戲：在地圖上移動、遇到並捕捉寶可夢，再挑戰道館 NPC。

## 功能

- **地圖探索**：讀入地圖檔，在終端機中以 `@` 表示玩家，用鍵盤移動；移動時會隨機遇到寶可夢
- **捕捉與管理**：遇到寶可夢時顯示 ASCII 圖像、種類與屬性，可選擇是否捕捉；可查看（`t`）或釋放（`r`）持有的寶可夢，最多持有 34 隻
- **道館對戰**：持有 3 隻以上才能挑戰，與 12 位 NPC 進行回合制對戰，記錄勝場數
- **屬性系統**：依屬性計算攻擊、防禦、速度與特殊能力

## 設計重點

- 以 `Pokemon` 為基底類別，13 種屬性各自繼承（`Type0`～`Type12`），透過**虛擬函式**覆寫攻擊、扣血等行為（多型）
- `Player`、`NPC`、`Battle` 類別分離玩家資料、對手與戰鬥流程
- 自訂例外 `Exception_dead` 處理寶可夢倒下的情況
- 使用 `rlutil.h` 控制終端機游標位置與顏色

## 技術

C++、物件導向（繼承、多型、例外處理）、Visual Studio

## 檔案

| 檔案 | 說明 |
|---|---|
| `main.cpp` | 遊戲主流程：地圖、移動、遭遇與選單 |
| `Pokemon.h`／`pokemon.cpp`、`Pokemon2r.h`／`pokemon2.cpp` | 寶可夢基底類別與各屬性子類別 |
| `Player.h`／`player.cpp` | 玩家資料與持有寶可夢 |
| `NPC.h`／`NPC.cpp` | 道館 NPC |
| `Battle.h`／`battle.cpp` | 對戰流程 |
| `Exception_dead.h`／`.cpp` | 自訂例外 |
| `rlutil.h` | 終端機控制函式庫（第三方） |

## 執行方式

用 Visual Studio 建立 C++ 主控台專案並加入所有檔案後編譯。執行時需要地圖檔 `yzumap.txt` 與寶可夢圖像檔 `001.txt`～`034.txt`（未包含在 repo 中）。

> 原始碼為 Big5 編碼，在 GitHub 網頁上中文可能顯示為亂碼，用 Visual Studio 開啟即可正常顯示。
