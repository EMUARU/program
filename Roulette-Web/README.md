# Roulette-Web：網頁輪盤遊戲

> 網頁程式設計課程的期末作品：玩家選擇籌碼與下注位置，轉動輪盤進行遊戲。

## 功能

- 初始資金 $10,000，可選擇 1～10,000,000 不同面額的籌碼
- 在 0～36 的號碼表上下注
- 以 Canvas 繪製輪盤並播放旋轉動畫，停下後依結果結算資金

## 技術

HTML、CSS、JavaScript（Canvas）

## 檔案

| 檔案 | 說明 |
|---|---|
| `final-project.html` | 主頁面 |
| `1.js` | 輪盤繪製、下注與結算邏輯 |
| `style.css` | 樣式 |
| `*.png`、`00.jpg` | 籌碼與背景圖片 |

## 執行方式

用瀏覽器開啟 `final-project.html`。
