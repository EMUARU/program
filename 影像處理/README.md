# 影像處理

> 影像處理課程的 7 份作業，使用 C++ 與 OpenCV 4.3（Visual Studio 2019）。每份作業的 `README.md` 有題目、實作方法與執行畫面。

| 作業 | 主題 | 主要方法 |
|---|---|---|
| [HW1](HW1/) | 像素值調整 | 灰階／RGB 判斷、像素運算與溢位處理 |
| [HW2](HW2/) | 影像與內切圓旋轉 | 仿射轉換、Trackbar |
| [HW3](HW3/) | Sobel 邊緣偵測與素描效果 | 高斯模糊、Sobel、二值化 |
| [HW4](HW4/) | 離散傅立葉轉換與高斯低通濾波 | DFT、頻譜／相位圖、頻率域濾波 |
| [HW5](HW5/) | HSI 色彩空間擷取黃色花瓣 | 色彩空間轉換、inRange |
| [HW6](HW6/) | Run-Length 無失真壓縮 | 顏色編碼表、連續長度編碼 |
| [HW7](HW7/) | 形態學運算計算圍棋個數 | 侵蝕、膨脹、Hough 圓偵測 |

## 執行方式

在 Visual Studio 建立 C++ 專案並設定 OpenCV，加入該作業的 `Source.cpp` 後編譯，依提示輸入圖片路徑（輸入 `0` 結束）。
