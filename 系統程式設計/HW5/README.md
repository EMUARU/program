# HW5：系統指令、shell 進階與字典查詢

| 資料夾 | 內容 |
|---|---|
| `part1/` | 實作小工具：`hostinfo`（主機資訊）、`mycat`、`mydate`、`printdir`（目前目錄）、`pipe_ls`（透過 pipe 執行 `ls`） |
