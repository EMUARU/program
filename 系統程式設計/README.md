# 系統程式設計（Network System Programming, 2023）

2023 年網路系統程式設計課程作業。每個資料夾內含 `題目` 與自己的實作，大多可直接 `make` 編譯。

| 作業 | 主題 |
|---|---|
| HW1 | File I/O：`tee` 實作、含 hole 的 `cp`（Ch.4） |
| HW2 | `tail` 實作（Ch.13 I/O buffering） |
| HW3 | 簡易 shell |
| HW4 | 系統與行程資訊（Ch.12） |
| HW5 | 常用指令實作、shell 的 pipe 與 I/O 重導、字典查詢 |
| HW6 | Pipes（Ch.44） |
| HW7 | Signals（Ch.22） |
| HW8 | FIFO、System V message queue（Ch.44、46） |
| HW9 | Memory mapping、message queue、shared memory（Ch.49、52、54） |
| HW10 | Shared memory + semaphore 生產者／消費者，含實驗報告 |
| HW11 | Socket：UNIX domain、TCP、UDP 字典伺服器 |
| HW12 | Inotify（Ch.19） |

> HW8、HW9 中的 `tlpi_hdr.h`、`error_functions.*`、`get_num.*` 為 *The Linux Programming Interface* 書附的輔助程式。
